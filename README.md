# homebrew-hearth

Homebrew tap for [Hearth](https://github.com/warrenseine/hearth).

```bash
brew install --cask warrenseine/hearth/hearth
```

This also installs [process-compose](https://github.com/F1bonacc1/process-compose) from its
author's tap (`f1bonacc1/tap`) if it isn't already there.

The app is unsigned (no Apple Developer ID yet) — see the cask's caveat for the one-time
Gatekeeper approval step.
